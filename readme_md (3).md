## 4. نظام المربعات الجغرافية المتدرجة ($L_1, L_2, L_3\text{ Grid System}$) والأكواد المعتمدة

يعتمد إطار العمل تقسيماً طبوغرافياً وعمرانياً ثلاثي المستويات لربط كل مشروع بنقطة جغرافية دقيقة في الخريطة الوطنية:

```
[ المحافظة: الكود السيادي مثل YE-TZ ]
   │
   └── [ المربع الرئيسي L1: نطاق المديرية والمركز الإداري والحضري ]
          │   (مثال: TZ-GRID-04 - مديرية المظفر / وادي القاضي)
          │
          └── [ المربع الفرعي L2: نطاق الحي السكني، العزلة، أو المحور التنموي ]
                 │   (مثال: TZ-GRID-04-B - حي النور والمحور الرابط)
                 │
                 └── [ المربع الدقيق L3: موقع المنشأة المحددة تفصيلياً ]
                        (مثال: TZ-GRID-04-B-01 - تقاطع الجسر المعلق ونفق المشاة)

```

### هيكل المستويات التخطيطية:

1. **المربع الرئيسي (**$L_1\text{ - Macro Grid}$**):** يمثل الإطار الجغرافي للمديرية بالكامل، ويتضمن دراسة المخطط الهيكلي العام، شبكات النقل الشريانية، وتوزيع استخدامات الأراضي الكبرى.

2. **المربع الفرعي (**$L_2\text{ - Meso Grid}$**):** يمثل الحي السكني، العزلة، المجمع الزراعي، أو المنطقة الصناعية المحددة؛ ويركز على البنية التحتية المحلية (المياه، الصرف الصحي، محطات الكهرباء، المدارس، والمراكز الصحية).

3. **المربع الدقيق (**$L_3\text{ - Micro Grid}$**):** يمثل قطعة الأرض أو الإحداثية المساحية الصريحة التي يقام عليها المشروع التنفيذي عينه (مبنى البرج، جسم النفق، أرصفة الميناء، محطة تحلية المياه، الحديقة العامة).

4. **تجهيز حزمة المخططات الفنية:** وضع ملفات التصميم (AutoCAD DWG, Revit RVT/IFC, ملف حساب الكميات Excel) داخل مجلد مضغوط وتسميته بكود المربع.

   * اسم الدكتور المشرف ورئيس القسم والعميد ورئيس الجامعة.

   * رقم الهاتف والواتساب لتتبع حالة المراجعة.

   * رابط التخزين السحابي للملفات المصدرية.
