## 4. نظام المربعات الجغرافية المتدرجة ($L_1, L_2, L_3 Grid System$) والأكواد المعتمدة

يعتمد إطار العمل تقسيماً طبوغرافياً وعمرانياً ثلاثي المستويات لربط كل مشروع بنقطة جغرافية دقيقة في الخريطة الوطنية:

```
[ المحافظة: الكود السيادي مثل YE-TZ ]
   │
   └── [ المربع الرئيسي L1: نطاق المديرية والمركز الإداري والحضري ]
          │   (مثال: TZ-GRID-04 - مديرية المظفر / وادي القاضي)
          │
          └── [ المربع الفرعي L2: نطاق الحي السكني، العزلة، أو المحور التنموي ]
                 │   (مثال: TZ-GRID-04-B - حي النور والمحور الرابط)
                 │
                 └── [ المربع الدقيق L3: موقع المنشأة المحددة تفصيلياً ]
                        (مثال: TZ-GRID-04-B-01 - تقاطع الجسر المعلق ونفق المشاة)
```

### هيكل المستويات التخطيطية:
1. **المربع الرئيسي ($L_1$ - Macro Grid):** يمثل الإطار الجغرافي للمديرية بالكامل، ويتضمن دراسة المخطط الهيكلي العام، شبكات النقل الشريانية، وتوزيع استخدامات الأراضي الكبرى.
2. **المربع الفرعي ($L_2$ - Meso Grid):** يمثل الحي السكني، العزلة، المجمع الزراعي، أو المنطقة الصناعية المحددة؛ ويركز على البنية التحتية المحلية (المياه، الصرف الصحي، محطات الكهرباء، المدارس، والمراكز الصحية).
3. **المربع الدقيق ($L_3$ - Micro Grid):** يمثل قطعة الأرض أو الإحداثية المساحية الصريحة التي يقام عليها المشروع التنفيذي عينه (مبنى البرج، جسم النفق، أرصفة الميناء، محطة تحلية المياه، الحديقة العامة).

* رفع تقارير دورية لرئاسة الجمهورية ومجلس الوزراء تتضمن لوحات المتابعة التراكمية ونسب إنجاز تغطية المربعات.
* اعتماد المخططات المكتملة وتقديمها رسمياً للمؤتمرات التنموية وصناديق الإعمار المحلية والإقليمية والدولية.

### 3. مسؤولية الهيئة العامة للأراضي والمساحة والتخطيط العمراني:
* تزويد البوابة بالبيانات المساحية، وخرائط الكاد (CAD Layer)، وخطوط التنظيم، والمناسيب الطبوغرافية للمربعات.
* مراجعة مدى توافق التصاميم مع المخططات الحضرية العامة للدولة ومنح شارة "مطابق للمواصفات المساحية".
* الرد الفوري على استفسارات الفرق الهندسية المتعلقة بحدود الملكيات ومحارم الطرق والأودية.

### 4. مسؤولية رؤساء الجامعات وعمداء كليات الهندسة:
* حصر كافة الفرق الطلابية وتوزيع مربعات المحافظة المحددة على الأقسام الهندسية بحسب التخصص.
* إصدار قرارات التكليف الرسمية للمشرفين والطلاب وتثبيتها في أرشيف الكلية.
* توقيع وتصديق استمارة حفظ الحقوق الفكرية والأكاديمية للفريق المشرف والمنفذ قبل الرفع للمنصة.

### 5. مسؤولية رؤساء الأقسام والدكاترة المشرفين:
* التوجيه الأكاديمي للفرق وضمان سلامة الحسابات الإنشائية، الكود الزلزالي، والمطابقة المعمارية البيئية.
* فحص التصاميم والنماذج المولدة بالذكاء الاصطناعي والتأكد من قابليتها للتنفيذ الهندسي الواقعي.
* المصادقة على ملف الميتاداتا (`registry_metadata.json`) واعتماده بالرقم المرجعي قبل تسليمه للبوابة.

### 6. مسؤولية الطلاب والمهندسين الخريجين والمستمرين:
* دراسة المربع المكلفين به دراسة ميدانية ومساحية معمقة وجمع البيانات عن التحديات والنقص التنموي.
* توليد المخططات الإنشائية والمعمارية (BIM, CAD, 3D Renderings) وحساب الكميات المبدئية والتكلفة التقديرية.
* إدخال البيانات كاملة وتوثيق مجهود الفريق بدقة، وحفظ الملفات في المستودع المخصص للمربع.

## 7. خطوات تشغيل المنصة والمستودع للجامعات (Quick Start Guide)

لضمان بدء الرفع الميداني في غضون دقائق، تتبع كل مجموعة هندسية الخطوات الست التالية:

1. **الوصول للبوابة الوطنية:** الدخول المباشر إلى واجهة الموقع الحي عبر الرابط الرسمي:
   `https://yemen-national-reconstruction-maste.vercel.app/`
2. **استلام كود المربع ($L_1/L_2/L_3$):** اختيار المحافظة والمديرية لمعرفة كود المربع الشاغر (مثال: `TZ-GRID-04-B-01`) وحجز النطاق الجغرافي.
3. **تطبيق برومبتات المحاكاة الهندسية:** استخراج المفهوم البصري وتحديد الكتل المعمارية باستخدام البرومبتات الرسمية وتكييفها مع محددات المربع المساحية.
4. **تجهيز حزمة المخططات الفنية:** وضع ملفات التصميم (AutoCAD DWG, Revit RVT/IFC, ملف حساب الكميات Excel) داخل مجلد مضغوط وتسميته بكود المربع.
5. **توثيق الفريق والمشرفين:** ملء الاستمارة الرقمية بتسجيل:
   * اسم الجامعة والكلية والقسم.
   * أسماء الفريق الهندسي بالكامل.
   * اسم الدكتور المشرف ورئيس القسم والعميد ورئيس الجامعة.
   * رقم الهاتف والواتساب لتتبع حالة المراجعة.
   * رابط التخزين السحابي للملفات المصدرية.
6. **الإيداع والتأكيد:** الضغط على زر **«اعتماد وتوثيق المشروع فورياً»** لاستخراج الكود المرجعي الفريد، ثم النقر على زر **إرسال الإشعار الرسمي عبر WhatsApp** لإيداع المشروع مباشرة في السجل الوطني بغرفة العمليات الهندسية الموحدة.
